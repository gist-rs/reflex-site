Typed decisions, calibrated honestly, on your machine.

Reflex answers choice, score, and yes/no questions about a state you give it — with calibrated confidence and a first-class abstain: when it has no signal, it declines instead of guessing. No trained weights on the decision path, no AI service, no telemetry. Loopback-only, microsecond-tier, bit-deterministic.

Three steps

The engine never phones home. The browser cannot reach it until you open the door for exactly one origin.

1 · Install

One binary. riir-reflex --version prints its compiled feature set and warns if the build is incomplete.

2 · Run with the door open

RIIR_REFLEX_ALLOWED_ORIGIN=https://reflex.gist.rs riir-reflex — the engine listens on 127.0.0.1:7331 and accepts browser calls from this page only.

3 · Play

Type a state and a question. Answers come back in microseconds, with confidence — or an honest abstain.

Give your coding agent a decision engine.

One file teaches your agent to drive Reflex properly — the wire, questions that work, thresholds fitted from your data, calibration, and the traps we found building this arena. Curl-installable, plain instructions, exact HTTP calls.

Claude Codemkdir -p .claude/skills/reflex-integration && curl -fsSL https://reflex.gist.rs/skills/reflex-integration/SKILL.md -o .claude/skills/reflex-integration/SKILL.md
Zed / any agentmkdir -p .agents/skills/reflex-integration && curl -fsSL https://reflex.gist.rs/skills/reflex-integration/SKILL.md -o .agents/skills/reflex-integration/SKILL.md
Which agents does it work with?

Claude Code reads .claude/skills/ natively; Zed reads .agents/skills/. And any agent that accepts a markdown instruction file works — the skill is plain instructions plus exact HTTP calls your agent already knows how to make.

What does it change?

Without it, an agent asked to classify, route, or triage reaches for an LLM call. With it, it starts a microsecond-tier local engine, asks typed questions with the answer space defined at request time, fits confidence thresholds from your labeled data, wires abstention into a fallback path instead of an error — and reports measured accuracy instead of a guess.
