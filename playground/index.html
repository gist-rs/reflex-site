This section is the one exception to "nothing is uploaded" — Ask Cloudflare sends the board below to the Worker (stateless: no storage, no logging of request bodies); Ask this tab sends nothing. Three steps

1 · Install

One binary. reflex --version prints its compiled feature set and warns if the build is incomplete.

2 · Run with the door open

RIIR_REFLEX_ALLOWED_ORIGIN=https://reflex.gist.rs reflex — the engine listens on 127.0.0.1:7331 and accepts browser calls from this page only.

3 · Play

Type a state and a question. Answers come back in microseconds, with confidence — or an honest abstain.
